0003: Read COCO + compute IoU by hand (once!)

Win: you can hand-compute agreement. This unlocks all quality + mAP intuition.

Jargon first:
• COCO JSON — Common Objects in Context. Stands for dataset + format with images, annotations, categories. Why called that: objects appear in everyday context. Why used: lingua franca — CVAT exports it, training + analysis read it.
• bbox [x,y,w,h] — bounding box. Stands for x-min, y-min (top-left corner in pixels), width, height. Why this order: COCO chose it; YOLO txt uses normalized center-x, center-y, w, h instead — different convention, same box. Don’t mix them.
• category_id — stands for number pointing to categories list (e.g. 1=helmet). Why a number not a name: compact + language-independent.
Formula: IoU (Intersection over Union) = intersection / union — see 0000 §4. Example: Box A [0,0,10,10] (area 100), Box B [5,5,10,10] (area 100). Intersection = 5×5=25. Union = 100+100−25=175 (minus one copy of double-counted overlap). IoU = 25/175 ≈ 0.14 → no match.

Do in Python (5 min)

python3 -c "
def iou(a,b):
    x1=max(a[0],b[0]); y1=max(a[1],b[1])
    x2=min(a[0]+a[2],b[0]+b[2]); y2=min(a[1]+a[3],b[1]+b[3])
    inter=max(0,x2-x1)*max(0,y2-y1)
    union=a[2]*a[3]+b[2]*b[3]-inter
    return inter/union if union else 0
print(iou([0,0,10,10],[5,5,10,10]))  # 0.14
print(iou([0,0,10,10],[1,1,10,10]))  # ~0.68 good
"
