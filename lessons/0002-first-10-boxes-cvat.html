0002: Your first 10 boxes in CVAT (local Docker)

Win: annotate 10 images locally, export COCO, open the JSON. 30 min.

Jargon first:
• CVAT — Computer Vision Annotation Tool. Stands for exactly that. Why called that: built by Intel/OpenCV for vision labeling. Why used: free, handles images + video tracks + review mode in one UI. Label Studio is easier but weak on tracking.
• Docker — stands for: shipping-container metaphor for software. Why called that: packs app + deps into isolated “containers”. Why used: CVAT needs DB + backend + frontend — one docker compose up runs all, no manual install.
• Project / Task / Job — stands for: CVAT hierarchy. Project = ontology + many tasks. Task = chunk of data (e.g. 10 images). Job = your slice to annotate. Why used: lets many people split work without clobbering.
Docs: CVAT install.

Steps

1. Run:
cd cvat
docker compose -f docker-compose.yml up -d
# open http://localhost:8080 → create superuser → login
If Docker is heavy, use cvat.ai cloud temporarily — same UI, export works identically.
2. Create Project: Name ppe-safety (PPE = Personal Protective Equipment, see glossary) → Labels: person, helmet, safety-vest → Create Task: upload 10 images from Roboflow Universe “hard hat”.
3. Annotate: Press N to create box, drag tight, choose label. Ctrl+S saves. Follow your 5 rules from 0001. Time yourself.
4. Export: Menu → Export → COCO 1.0 → save to data/processed/annotations.json. COCO — Common Objects in Context. Stands for the photo dataset + JSON format. Why called that: photos show objects in context (kitchen, street), not isolated. Why used: standard images / annotations / categories structure every tool reads. Open it: find those 3 keys.

Quiz

Q: You export and bbox is [100,50,80,120]. What is it?

Ask agent: “my export looks wrong, here’s the JSON”.
